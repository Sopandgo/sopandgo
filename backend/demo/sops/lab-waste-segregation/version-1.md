# Lab Waste Segregation (Demo)

## 1. Purpose

This procedure describes which waste goes into which container.

## 2. Scope

All waste produced in the lab rooms.

**Disclaimer: This is a demonstrational document only and should not be used for actual laboratory work without verification by qualified personnel and adherence to local waste regulations.**

## 3. Responsibilities

* Everyone sorts their own waste at the bench.
* The lab manager arranges pickup of full containers.

## 4. Waste Streams

| Waste | Examples | Container |
| --- | --- | --- |
| **Sharps** | Needles, scalpels, broken glass | Yellow puncture-proof box |
| **Biological** | Cultures, contaminated tips and plates | Autoclave bag, then general waste after autoclaving |
| **Chemical, liquid** | Solvents, staining solutions | Labeled canister in the fume hood |
| **Chemical, solid** | Contaminated gels, absorbents | Labeled solid chemical waste bin |
| **General** | Packaging, clean paper towels | Regular bin |

## 5. Rules

1. Never mix halogenated and non-halogenated solvents.
2. Close all containers when you are not adding waste.
3. Replace sharps boxes when they are three-quarters full.
4. Label every chemical waste container with its contents and the start date.
5. If you are unsure, ask the lab manager before you dispose of anything.
