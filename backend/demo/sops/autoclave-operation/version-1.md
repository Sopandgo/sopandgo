# Autoclave Operation (Demo)

## 1. Purpose

This procedure describes how to sterilize liquids, glassware, and waste in the benchtop autoclave.

## 2. Scope

The lab's benchtop steam autoclave.

**Disclaimer: This is a demonstrational document only and should not be used for actual laboratory work without verification by qualified personnel.**

## 3. Responsibilities

* Only trained users may run the autoclave.
* The lab manager arranges yearly maintenance.

## 4. Safety Precautions

| Hazard | Source | Mitigation |
| --- | --- | --- |
| **Burns** | Hot steam and loads | Wear heat-resistant gloves and a lab coat. Open the door slowly. |
| **Boil-over** | Superheated liquids | Wait until liquids have cooled below 80 °C before moving them. |
| **Pressure** | Sealed containers | Never autoclave closed bottles. Loosen all caps. |

## 5. Procedure

1. **Check:** Make sure the water reservoir is filled and the drain is clear.
2. **Load:** Place items in an autoclave-safe tray. Loosen caps and add autoclave tape.
3. **Select cycle:** Use "Liquids" for media and "Solids" for glassware and waste.
4. **Run:** Close the door and start the cycle (121 °C for at least 20 minutes).
5. **Unload:** Wait until the pressure reads zero, then open the door slowly.
6. **Verify:** Check that the autoclave tape has changed color.
